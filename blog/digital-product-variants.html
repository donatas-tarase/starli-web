How to deliver different files for product variants in Wix

Written November 3, 2026 · Starli Labs

Illustrative app view.

One product can come in several useful forms: a planner for printing or a tablet, a template in two formats, or a starter and an extended pack. The important part is that the customer receives the files associated with the option they actually chose.

Starli Digital Downloads can connect files to supported Wix products and existing product variants and deliver them after a paid order. Before planning a multi-option offer, check that your Wix product setup supports the options you need, then test each buying path.

Check whether your Wix product supports options

Wix currently states that its native digital products cannot be created with product options. See the Wix feature request for digital product options for the current limitation. Starli can map files to supported existing product variants, but it does not create native Wix digital-product options. Check that your catalog setup and purchase flow support the variants you intend to use before relying on this guide. If they do not, consider separate product listings and contact support about your setup.

When does a variant need a different file?

Where your Wix product setup already supports variants, use them when the options belong to the same product but the buyer chooses between clearly defined versions. For example, a printable planner and a tablet-ready planner solve the same problem, yet require different files. A downloadable design pack might offer SVG and PNG formats, while a music producer might sell a track in separate audio formats.

The option name should describe the difference a buyer will notice. “Printable PDF” is clearer than “Version A.” Mention the file format, software requirements and any licence differences in the product description. A buyer should not have to open the delivery email to learn what they purchased.

Map your options before uploading

Create a small planning table with one row for every option a customer can purchase. List the exact files and what each file is for. Here is an illustrative example:

Customer choosesFiles to deliverWhat to explain
Printable plannerPrintable-planner.pdfPage size and printing guidance
Tablet plannerTablet-planner.pdf and setup guideCompatible apps and setup steps

The names above are examples. Your files may use another format or include several items. Confirm that you have the rights to distribute each file and that any included fonts, graphics or other assets have the appropriate licence.

Connect the files to the product options

  1. Review your existing Wix product. Confirm your catalog setup supports the product variants you intend to use. Check that each available option has a distinct name matching the description customers see.
  2. Prepare the files. Open each final file, check its name and contents, and keep a clear copy for each option. If a download includes multiple files, make the set easy to understand.
  3. Connect the relevant files. In Starli Digital Downloads, find the product and associate the appropriate files with each available variant. Review the variant names as you work.
  4. Review access settings. Check the rules applicable to the product and your plan, including any download limit or expiry you intend to communicate to buyers.
  5. Test each option. Follow the purchase and delivery journey for every variant that matters before promoting the listing.

Product and variant configuration can differ between Wix catalog setups. If an expected option is not visible, check the product in Wix and refresh the app’s product view before assuming the mapping is complete. If the issue remains, contact support with the product name and a description of the missing option.

Make the choice clear before checkout

A file can be correctly mapped and still disappoint a customer if the listing sets the wrong expectation. Use the product description and images to make the distinction obvious: printable versus digital, editable versus ready to use, or a single file versus a bundle. Show what is included in each option.

Include any requirements that affect usability. A template may need particular software; a printable may have a specific page size. If the options have different licences, describe the permitted use before purchase and provide the relevant terms with the product. Avoid promising an option is compatible with every device or application unless you have tested it.

Test what the buyer actually receives

Make a controlled test purchase for each option using your normal test process. Once the order is paid, open the delivery email, follow the download link and compare the files against your planning table. Open the downloaded files, not just their filenames. For a bundle, extract and inspect its contents.

Also check a mobile inbox and a desktop browser when possible. Does the buyer understand which file to open? Can they find any included instructions? If the wrong file arrives, pause promotion of the affected option, review the mapping and repeat the test after making changes.

What about changes after an order?

When you replace a file or edit a variant, think about two groups separately: customers who buy next and customers who already ordered. Do not assume an old order automatically receives the newly mapped file. Review the order and the app’s available file-version controls before promising an update to previous buyers.

Likewise, a customer entering custom text is not necessarily the same as selecting a predefined variant. Wix notes that a separately customised digital file may require a separate delivery process. Check the Wix digital product guide and design your workflow around what you can actually fulfil.

Frequently asked questions

Can two variants use the same file?

They can be planned to include the same material where it belongs in both offers. Review each variant’s mapping and test the resulting order rather than assuming a file has been attached everywhere.

Should I use a variant or a separate product?

A supported existing variant can help shoppers choose between versions of one product. Wix currently does not offer product options on its native digital products, so check your setup first. Separate listings may be clearer when options are unavailable or the offers and audiences differ. Choose a structure customers can understand before checkout.

What happens to a previous buyer when I change a file?

Review the existing order and version settings. A change to a current mapping should not be assumed to rewrite a previous order’s access.
