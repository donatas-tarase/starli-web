Workflow Automation & Triggers overview

  • Start with business templates and customize each stage
  • Configure supported events, conditions and ordered actions
  • Choose products and supported records by name
  • Manage workflows, accepted triggers and plan usage

Start from a business template, then customize its events, conditions and actions in one dashboard. Create a single-event workflow or group several real event stages into one customer journey.

React to store orders, checkout activity, Pricing Plans and supported events from installed business tools. Select products and supported records by name. Use event details in conditions and actions without writing expressions or pasting record IDs.

Arrange supported actions such as contact labels, follow-up tasks, HTTP requests and timed steps. Save personal templates, edit workflows and review accepted triggers separately from monthly plan usage.

Each journey uses one active-workflow slot; each matching stage uses a trigger allowance. Available events and actions depend on installed tools, permissions and complete configuration. Fulfillment does not confirm delivery. Purchase history and saved site-currency rules apply. App and native action limits are separate.
